# 口播成稿通用手册（多 IP）

> ⚠️ **本 skill 不含任何人设。** 人设、语气、CTA 全部来自 `ip-persona-resolver` 解析出的人设卡。
> 谁的人设卡没拿到，就不许动笔。

## 一、动笔前的顺序（不可颠倒）

1. **解析 IP**（`ip-persona-resolver`）→ 拿到注入块，确认定位、受众、语气、CTA
2. **确认输入** — 已选定的选题与立意点 / 说给谁听 / 内容目标 / 平台
3. **确认字数** — **全包统一 ≤700 字（硬上限，任何 IP 无例外）**，建议落在 620–700 字。
   卡上若还写着别的规格（650–850 / 1100 / 720–880 / 300–450…），**一律按 700 上限执行**：不报冲突、不放宽、也不要为此停下来问用户。
4. **看对标（推荐，`ip-benchmark-refs`）** — 按这个 IP 的定位现场挑 1–3 位对标博主，
   只取「可借鉴机制」与结构方法。**借机制，不借内容**：不借履历、不抄原句、不把标题当正文依据。
   库建议的正文链「具体困境 → 真实经历 → 判断变化 → 原因解释 → 行动建议」与五层结构是一回事
   （映射见该 skill 第五节）。库里写的「约 90 秒 / 两行封面文案 / 一个评论问题」**不改本包规格**。

信息没给全时，**只追问会明显改变立意或成稿的 1–2 个问题**，其余合理推断。

遇到政策、数据、新闻、金融、保险或时效性选题，**先核实最新来源**（ima 知识库 + WebSearch）。来源留在「事实备注」，不进口播正文。

## 二、默认规格：≤700 字口播

| 时长 | 字数 |
|---|---|
| 30 秒 | 180–220 字 |
| 45 秒 | 270–330 字 |
| 60 秒 | 360–440 字 |
| 90 秒 | 540–660 字 |
| **默认（全包统一，所有 IP 无例外）** | **≤700 字，硬上限 700**，建议落在 **620–700 字** |

语速按**约 360–440 字/分钟**（快节奏口播）换算——上表每个字数区间都是按这个口径算出来的。
**700 字 ≈ 1 分 40 秒。**

> ⚠️ **上限是硬的**：任何 IP 都不能突破 700 字，人设卡上的旧规格一律作废（2026-09-22 用户拍板：成片太长）。
> 曾经出现过的 720–880 / 650–850 / 硬上限 1100 / 每月 1–2 条约 4 分钟长视频等写法，**全部取消**。

## 三、五层结构（≤700 字版）

| 层 | 时间 | 字数 | 功能 |
|---|---|---|---|
| **钩子层** | 0–8 秒 | 45–55 | 制造注意力劫持 |
| **铺垫层** | 8–30 秒 | 120–145 | 建立信任与期待 |
| **主体层** | 30–86 秒 | 325–375 | 传递核心价值 |
| **升华层** | 86–96 秒 | 58–68 | 提升认知或情感高度 |
| **引导层** | 96–105 秒 | 45–55 | 引导互动或关注 |

五层合计 **593–698 字 / 约 1 分 40 秒**，天然卡在 ≤700 字上限之内——**按这张表分配就不会超**；真超了先砍主体层的重复论证，不要动钩子和升华。

**其他时长按同比例缩放**，不要照搬 60 秒模板的时间点。

## 四、三大核心密码

1. **情绪波浪** —— 不是平铺直叙，是一波一波推进，**每 15–20 秒一个小高潮**
2. **信息钩子链** —— 全文埋 **3–5 个信息钩子**，让观众始终处于「想知道下一个」的状态
3. **价值递进** —— 价值感从头到尾递增，**最大的价值放在最后**，锁定完播

## 五、逐层写法

> 这一节给**骨架**，第六节给**文字**。两节都要过——只搭对骨架、文字还是 AI 腔，不算完稿。

### 1. 钩子层（0–8 秒）
1–2 句，**不寒暄，不说「今天跟大家聊聊」**。
优先：痛点 / 悬念 / 利益 / 身份冲突 / 反常识。
**必须是爆款开头，第一句就要有冲突或反差——硬要求见 §6.5。**
**各 IP 的禁用范式见人设卡**（如 TC 禁用「大家好我是…」「最近很多人问我…」）。

### 2. 铺垫层（8–30 秒）
摆出现象或冲突，建立「这个人懂我在说什么」的信任，同时埋下第一个信息钩子。
不要在这里就把结论说完。

### 3. 主体层（30–86 秒）
通用骨架：**拆开原因和机制 → 拉回观众处境**。
每推进一层补一个新信息、对比、画面或问题。
中后段只放**一个最强转折**：用「你以为 X，其实 Y」颠覆旧认知，或把个别现象上升为结构、规则或人性判断。

### 4. 升华层（86–96 秒）
把观点抬到认知或情感高度，用一句可单独截取的**金句**收住核心价值。不引入新知识。
**这一句要经得起单独截图发出去——写法见 §6.6。**

### 5. 引导层（96–105 秒）
按内容类型给一个动作。CTA 按 IP 卡执行——有的是固定品牌语，有的按类型分流。
**结尾必须先给一个当天能做的具体动作，再落 CTA；互动或口号必须有一句——见 §6.6。**

## 六、去 AI 味写作法（硬规范 · 所有 IP 通用）

> 第五节给骨架，这一节把文字从「标准答案」掰成「人在说话」。
> **五层骨架 + 去 AI 味文字，才算完稿。**通不过这一节的，退回重写，不接受「局部润色」。

### 6.1 三条总纲

1. **像人，不像模型** —— 任何一句都不该让人「闻到」AI 味。
2. **说事，不说「我」** —— 论据是事实、机制、观众自己的处境，不是「我觉得」。
3. **留呼吸，不留工整** —— 长短句交错，允许一点毛边。四平八稳、句句对仗，本身就是 AI 味。

### 6.2 语言层：十条对照

| # | 规则 | ❌ 这样写（AI 腔） | ✅ 这样写（人味） |
|---|---|---|---|
| 1 | **长句拆短，长短交错** | 「在当下快速变化的环境里，我们不难发现很多人的选择正在发生转变。」 | 「变快了。快到什么程度？去年还算优势的东西，今年不算了。」 |
| 2 | **少用被动，多用主动** | 「这笔钱被普遍认为是安全的」 | 「很多人觉得这笔钱稳妥」 |
| 3 | **空泛抽象词换成能看见的东西** | 「提升家庭抗风险能力」 | 「明天急用钱，你几天能凑出来」 |
| 4 | **不背套话连接词** | 「首先…其次…值得一提的是…综上所述」 | 直接说下一句，靠内容承接，不靠过渡词硬接 |
| 5 | **一句话只干一件事** | 一句里塞三个分句、两次转折 | 拆成三句，一句一个信息 |
| 6 | **动词优先，别名词化** | 「对资产进行一次规划」「做一次了解」 | 「把这笔钱分成三份」「去查一下」 |
| 7 | **写具体的名和数** | 「不少家庭」「某个比例」 | 「一套房」「两成多」 |
| 8 | **适度口语停顿** | 一口气念不完的长段 | 「说白了——」「注意，是少招人，不是裁员。」 |
| 9 | **允许毛边** | 每句都工整对仗、三段式排比 | 偶尔甩一个更短的判断句，不追求齐整 |
| 10 | **同一个句式只用一次** | 全文三次「不是 A，是 B」 | 金句骨架只留一次，其余换说法 |

### 6.3 视角层：把「我」从主角位上撤下来

- 叙述主体是**这件事**和**你**，不是「我」。
- 「我」只允许出现在两处：① 钩子里的设问（「换成我，我在防什么？」）；② 结尾按人设卡的身份 CTA。**其余位置一律不出现。**
- **禁**自我担保句式：「我觉得」「我认为」「在我看来」「以我的经验」「我作为…」。
- **禁**媒体自指：「本视频」「这一期」「今天跟大家聊」。
- 别替观众下结论——把算账的动作交回给他（「你自己算一算」），让他自己说出那个结论。
- 例外：IP 卡若明确要求第一人称表达，**以卡为准**；但「我觉得 / 我认为」这类自我担保句式在任何 IP 下都禁用。

### 6.4 情感层：言之有理，动之以情

- **有理**：抛出一个判断，后面必须跟得住一个依据——数字、机制、或一个能被验证的场景。不空喊。
- **动情**：每 2–3 句里落一个**观众认得出来的具体画面**（公屋的队列、体检报告上的箭头、月供那一笔、翻到包装背面看产地）。
- **共鸣**：不写「很多人都这样」，直接写「你是不是也这样」——把观众请进来，别把他当研究对象。
- **不预设观众傻**：用「你想想」，不用「大家可能不知道」。

### 6.5 开头（钩子层）：必须是爆款开头

钩子层 45–55 字，1–2 句。**第一句就要有冲突或反差**，不许把铺垫拖到第二句。

| 起手式 | 样子 |
|---|---|
| **反常识断言** | 「AI 没抢你的工作，它拆的是你的梯子。」 |
| **能看见的数字或场景** | 「很多家庭，把八成的身家押在一套房上。」 |
| **直呼观众处境** | 「利息低到可以忽略，还是有人排队去抢。」 |

**禁**：新闻播报式起手（「最近有一个现象」）、寒暄式起手（「今天跟大家聊聊」）、背景介绍式起手（「随着…的发展」）。
第一句里**不出现「我」**；**第一句 ≤35 字**，钩子层整体仍按第三节表格的 **45–55 字**（两句合计不超过 55 字）。

### 6.6 结尾：先收，再抬，最后递动作

- **先收**：升华层用一句能**单独截图发出去**的金句收住全文——「一个具体意象 + 一个判断」，不要抽象名词堆叠。不引入新知识，不重述主体。
- **再抬**：这一句是全片情绪最高点，价值感必须高于前面任何一句。
- **递动作**：引导层先给一个**当天就能做的具体动作**（「今天就做一件事：把你家的钱分三层看看」），再落该 IP 的**固定 CTA**。
- **结尾必须有一句互动或 CTA 口号**，二者可并存。互动 = 把问题抛回观众（「你手上有没有这样一份长期承诺？」）；CTA = 人设卡里的固定品牌语。
- **禁**：「综上所述」「希望对你有帮助」「感谢观看」。

### 6.7 排版：一句一段算事故

- 按**文章方式组织段落**，同一段内容留在同一区块内。**输出不要一句一段。**
- 禁止「三行一段 + 空行」的 AI 式排版。需要停顿就在段内换行。
- 正文**纯文字**：不加粗、不斜体、不项目符号、不表格、不分隔线、不用 emoji（`【】` 是唯一允许的标记）。

### 6.8 出稿前「去 AI 味五问」（逐条答，有一条答不上就回去改）

1. 念一遍，有哪句像 PPT 上的字？
2. 有没有「我」站在台上讲课的感觉？
3. 有没有一口气念不完的长句？
4. 抽象词能不能换成具体的东西？
5. 最后那句金句，能不能单独截图发出去？

## 七、成稿硬规范（所有 IP 通用）

1. **字数一律 ≤700（硬上限，无例外）**，建议落在 620–700；不得套用其他 IP 的旧规格数值。
2. 完整视频文案必须是**纯文字**：不加粗、不用斜体、标题、项目符号、引用、表格、分隔线、颜色、表情符号或其他富文本格式。
3. 不要为了制造口播节奏把每句话拆成独立文本区块。同一段内容保留在同一文本区块内；需要停顿时在当前区块内换行。
4. **减少换行**，按文章方式组织段落。
5. 连续句子自然衔接，确保复制到微信、小红书、剪映后仍整洁易读。
6. 资料来源只放「事实备注」，不塞进正文。
7. **用【】标注需要特别强调的语气重点**（这是唯一允许的标记符号）。

## 九、出稿前检查清单

**通用项（所有 IP 都查）**
- [ ] 已拿到并遵循该 IP 的人设卡（不是别的 IP 的）
- [ ] 字数 **≤700**（建议 620–700），五层字数分配大体符合上表
- [ ] 五层结构齐全，每层功能明确
- [ ] 前 8 秒能让目标观众停下来，且不在该 IP 的禁用范式内
- [ ] 每 15–20 秒有一个情绪小高潮
- [ ] 全文埋了 3–5 个信息钩子
- [ ] 最大价值放在最后（不是开头就说完）
- [ ] 每 10 秒至少一个信息点或情绪触发点
- [ ] 全片只有一个主观点
- [ ] 中间至少一次递进 + 一次认知转折
- [ ] 每个数字都解释了「跟观众有什么关系」
- [ ] 至少一个具体场景或画面
- [ ] **100% 口语**，无书面语痕迹，读起来像真人在聊天
- [ ] **去 AI 味五问（§6.8）逐条答过，全部答得上**
- [ ] 长句已拆短，长短句交错；没有一口气念不完的句子
- [ ] 被动语态已改主动；无「首先/其次/综上所述/不难发现」等套话连接词
- [ ] 抽象词已换成能看见的东西；至少 3 处具体画面或数字
- [ ] 「我」只出现在钩子设问和结尾 CTA（**人设卡明确要求第一人称的 IP 以卡为准，见 §6.3 例外条款**），全文无「我觉得/我认为/在我看来」
- [ ] 开头第一句有冲突或反差，且不含「我」；**第一句 ≤35 字**，钩子层整体 45–55 字
- [ ] 全文无同一句式反复（「不是 A，是 B」类骨架只出现一次）
- [ ] 正文纯文字，**按段落组织，没有一句一段**，换行克制
- [ ] 无虚构经历、客户故事、数据或政策
- [ ] 无夸大收益、制造恐慌、强行推销
- [ ] 结尾先收观点，再给一个动作
- [ ] 已给出字数（须 ≤700）、预计时长与口播建议

**IP 专属项（从人设卡逐条抄进来核对）**
- [ ] 必用词/句式已用
- [ ] 禁用词/失效标题一个都没出现
- [ ] CTA 与内容类型匹配
- [ ] 港险承接方式符合该 IP 的设定
