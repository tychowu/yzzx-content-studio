## 一句话定位
**面向内地家庭的「香港实用生活翻译者」**——用攻略和工具视频，帮人把香港生活真正过明白。

## 五个身份锚点（真实，不可虚构）
1. **部队大院成长** — 底色直率、能吃得住事
2. **曾任税务局公职** — 懂规则、懂合规的分寸感
3. **2017 年入行保险，3 个月达成 MDRT、次年 COT** — 专业背书
4. **疫情期间做社区团购，积累了客户资源** — 懂普通人怎么盘算生活
5. **热爱运动、外形有网感、有香港生活经验**

**个人特质**：直率、能让人信任、能量强。

## 受众
- **核心客群：有消费能力的已婚女性 / 妈妈群体**——家庭条件好、老公赚钱，自身渴望独立与财务自由
- 内容漏斗：**先吸引所有对香港感兴趣的人 → 筛选女性 → 留下对 Tina 本人感兴趣的潜在客户**

## 内容配比
**70% 实用攻略 ＋ 30% 个人标签强化**（情感 / 观点 / Vlog）

## 格式参数
- 字数：**≤700 字（全包统一硬上限，无例外）**，建议落在 620–700 字
- 结构：**前三秒必须钩子 / 反差感**，避免口播式纯保险介绍
- 剪辑：**干净简洁、少特效**——李老師曾测试高级特效但无流量，此路已验证不通
- 发布：**每周 3 条**（一三五或二四六），**上午 10–11 点**（现多为下午，需优化）
- 封面：每条视频额外录一张**自拍封面图**，配合内容做表情动作
- 拍摄注意：**手势要多样化**（已成肌肉记忆，需刻意变化）

## 选题方向（七类，已确认）
| 类别 | 示例 |
|---|---|
| **城市效率类** | 香港地铁为何不用安检、香港机场效率解析 |
| **实用攻略类** | 港漂生存指南（交通/美食/购物/医疗）、来港五大必备 APP、买机票补贴攻略 |
| **法制避雷类** | 过海关规则（带雪茄/腊肉/烟草被罚真实案例）、公共场所规则、学历造假后果 |
| **教育类** | 香港幼儿园阶层划分、孩子独立出行、操行分重要性 |
| **身份规划类** | 什么样的家庭适合规划香港身份、孩子几岁来港合适 |
| **财商/投资类** | 个人投资经历、踩过的坑、房产/金融决策分享 |
| **运动/生活类** | 徒步麦理浩径、香港免费资源盘点 |

**爆款逻辑**：高赞内容踩中 **利他性**（观众能"拿走"有用信息）+ **工具性**（可直接转发给客户）。
**工具视频**是验证有效的主力——能转给客户当谈资和钩子。

## 前 3 秒钩子
必须有**钩子或反差感**，禁止平铺直叙的口播式开场。

## 语气
直率、有能量、可信赖。讲实用信息为主，是"能帮你把事办成"的姐姐，不是说教者。

## 港险承接
**避免口播式纯保险介绍**。港险类做成**工具视频**（如「买港险给孩子储蓄值不值」——只做工具、不教人选品就 OK）。
⚠️ **合规红线**：「买香港保险被投诉了」这种角度**百分之百违规，肯定会出红线**。

## 流程开关
**与全包一致：先出 10 个选题 × 5 个立意 → 用户勾选选题并选定立意 → 才写稿。无例外。**

## 硬禁用
- ❌ **深度思考 / 人性教育 / 鸡汤类** —「现阶段发这种鸡汤的内容可能不是很合适」（如「人生只剩下四百周」已建议往后延）
- ❌ **历史题材** — 本人明确「我不喜欢历史」。（香港供水史虽全 IP 推荐，但 Tina 版不要派）
- ❌ 口播式纯保险介绍
- ❌ 高级特效剪辑（已验证无效）
- ❌ 「买香港保险被投诉了」类负面角度（违规红线）
