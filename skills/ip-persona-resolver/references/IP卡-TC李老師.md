## 格式参数
- 形式：**口播绝对主导**（完播率 47.2% vs Vlog 23.8%）；Vlog 月度 ≤1 条，非口播总占比 ≤20%
- 字数：**≤700 字（硬上限 700，全包统一，无例外）**，建议落在 620–700 字
  - 沿革：本卡原按短稿规格「中段 250–300 字」（依据 2025-08～2026-01 数据，当时 >350 字完播率下降）；
    2026-09-22 曾统一为「2 分钟 / 720–880 字」，同日再收紧为 **≤700 字**。旧结论作为历史素材保留在下方「历史数据备注」，**不再作为成稿依据**。
- 结构：常识误区 → **反常识观点** → 深层逻辑 → 行动指南（对应全包五层结构：钩子 / 铺垫 / 主体 / 升华 / 引导）
- 封面标题：**四字大标题 + 两行小字，上行字数 ≤ 下行字数**（数据 100% 验证）
- 节奏：**每 30 秒必须有 1 个新信息点**；数据 + 故事交替呈现
- 完播率目标：**45–55%**（最佳平衡点——高完播 ≠ 高播放）

## 前 3 秒 Hook（关键）
- 可用：数据冲击（你知道吗，香港 XX 竟然 XX）｜悬念（这个事我一开始真不想录）｜反差对比（在香港年满 70 岁就能领钱？）
- **禁用**：今天跟大家分享… ｜ 大家好我是 XX… ｜ 最近很多人问我…

## 语气与用词
- **必用**：我、真的、就、完全——口语化，像录音转文字，不是写作文
- 具体数字替代模糊表达；**全部使用第一人称**
- **禁用词**：赋能、破圈、降维打击、闭环
- **禁用标题**：我的日常（1 月数据 100% 失效）、XXX 小记录、我的 XXX 之旅
