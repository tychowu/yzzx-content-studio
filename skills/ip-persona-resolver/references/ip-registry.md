## 别名解析规则

1. **精确匹配**标准名 → 直接命中
2. **精确匹配**别名表任一 → 命中对应标准名
3. **子串包含**：用户句子里含某个别名（如「给爱酱写一版」）→ 命中
4. **繁简/错拼容错**：`老师↔老師`、`TC李老師↔TC李老师`、`Ashely↔Ashley`
5. **命中多个** → **列出候选让用户确认**，严禁自行挑选
6. **一个都没命中** → 停止产出，问用户是不是新 IP；确认后提示在 Notion 建卡并**回写本表**
