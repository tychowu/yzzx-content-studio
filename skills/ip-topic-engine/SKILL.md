# 选题引擎（多 IP 通用）

> 本 skill 管「选什么题」，不管「怎么写」。写法参数（结构、语气、钩子）来自 `ip-persona-resolver` 的 IP 卡。
> **字数全包统一：口播稿 ≤700 字（硬上限，无例外）**——选题能不能展开，一律按这一条判断。

## 一、核心命题

各大平台对**保险内容**限流，但不对**有保险思维的生活内容**限流。

所以选题的基本盘是：**用大众兴趣点做入口，用保险/财经思维做内核，落到个人选择。**

> 一句话公式：**大众情绪入口 + 一个反常识的风险/利益视角 + 落到「你该怎么选」**

绝对不要讲产品、讲条款、讲公司、讲收益演示。要讲的是**一种看待风险和未来的思维方式**——这才是不掉调性又能吸引潜在客户的东西。

## 二、大兴趣点 × 保险思维映射

> **下列六类只是参考起点，不是封闭清单。**
> 抓热点时可以自行归纳新的大兴趣点类别（AI 冲击、移民抉择、养老现实、婚育成本、身份规划……），
> 只要它能接上保险思维内核就行。**不要被这六类框住。**
> 其中**第 6 类「香港故事」是常备主线**——香港向 IP 的选题池里，这类可以稳定占 1–3 个。

每一个选题必须同时命中左侧的「大众入口」和右侧的「思维内核」之一。命中两侧，才有传播又有转化。

### 1. 柴米油盐：衣食住行与生活刚需

| 大众入口 | 保险思维内核 |
|---|---|
| 香港物价 / 内地物价对比 | 购买力与通胀：钱放在哪里会被时间吃掉 |
| 租房还是买房 | 负债 vs 流动性：选择权的成本 |
| 孩子上学、择校、学区 | 长期现金流承诺：教育金的本质是时间契约 |
| 一顿饭、一杯咖啡的价格 | 复利的生活化翻译 |
| 香港生活成本真相 | 确定性溢价：为什么有人愿意为稳定多付钱 |

### 2. 焦虑与晋升：职场、副业与赚钱

| 大众入口 | 保险思维内核 |
|---|---|
| 35 岁焦虑、被优化 | 风险管理：个人也有「核保」逻辑 |
| 副业刚需、斜杠青年 | 收入结构单一 = 没有对冲 |
| 裁员、降薪、跳槽 | 现金流缓冲垫厚度决定选择权 |
| 高才通 / 优才 / 港漂求职 | 身份也是一种资产配置 |
| 老板 vs 打工的差别 | 风险承担方 vs 风险转移方 |

### 3. 情绪宣泄：情感、婚恋与社会热点

| 大众入口 | 保险思维内核 |
|---|---|
| 婚姻、离婚、婚前财产 | 契约精神与风险隔离 |
| 家庭责任、上有老下有小 | 家庭财务的脆弱点在哪 |
| 独生子女一代的两难 | 代际风险传递 |
| 朋友借钱、合伙翻车 | 信任的成本与制度兜底 |
| 社会新闻里的人生翻车 | 概率思维：小概率事件的毁灭性 |

### 4. 变美与健康：容貌焦虑与养生自救

| 大众入口 | 保险思维内核 |
|---|---|
| 医美、抗衰、容貌焦虑 | 长期投入 vs 短期效果，健康折旧率 |
| 体检报告看不懂 | 早发现的价值 = 风险前置管理 |
| 年轻人养生、熬夜 | 不可逆损耗与止损思维 |
| 心理健康、情绪内耗 | 心理韧性也是一种抗风险能力 |
| 健身、饮食自律 | 自律的本质是给未来买保险 |

### 5. 猎奇与解压：冷知识、历史悬疑与副业故事

| 大众入口 | 保险思维内核 |
|---|---|
| 历史上的金融泡沫 | 人性贪婪与周期规律 |
| 冷门职业、奇葩副业 | 风险定价：为什么这个活儿贵 |
| 其他城市的兴衰对照（香港故事见第 6 类） | 制度演进背后的风险管理智慧 |
| 富豪家族兴衰 | 传承失败的真实原因 |
| 悬案、骗局、反转 | 信息不对称与信任机制 |

### 6. 香港故事：名人、城市与旧行业（香港向 IP 的常备主线）

| 大众入口 | 保险思维内核 |
|---|---|
| 香港名人 / 富豪的发家与结局 | 财富的攻守转换：赚得到靠能力，守得住靠结构 |
| 家族争产、遗嘱纠纷、二代接班失败 | 传承失败的真实原因：没有提前安排 |
| 老行业兴衰（船务、洋行、转口贸易、制衣、钟表） | 行业周期里的个人风险定价 |
| 香港城市变迁（中环、庙街、九龙城寨、天星小轮、公屋） | 城市也有扩张期与收缩期，个人要有对冲 |
| 香港制度小事（强积金、丁屋、八达通、医疗券） | 公共安全网的边界在哪里 |
| 港人移民与回流故事 | 身份与资产的跨境安排 |
| 老香港的职业与手艺消失 | 不可逆变化下的止损与转换思维 |
| 港片港剧与流行文化里的财富隐喻 | 大众情绪入口，最后落到个人选择 |

**用这条线的两条硬规矩：**

1. **事实可核** —— 人名、年份、地名、数字一律查证，查不到标【待核实】。
   **严禁编造名人事迹、家族八卦或道听途说的细节**——这是品味红线里「编造」那一条。
2. **必须落到机制，不能只讲故事** —— 故事只是入口，讲完要给出一句关于风险、周期或传承的洞察。
   只复述历史、落不到「你该怎么选」的，按六道闸第 2 条丢弃。

**适配度**：最贴合定位里带「香港视角 / 香港观察」的 IP —— **胡子哥（香港观察者）、香港小黑哥、
Tina港生活、湾区E姐**。Ashley / Eva / TC李老師 也能用，但要从各自客群切入
（港漂认同 / 女性视角 / 教学视角），不要硬讲香港史。

## 三、选题质量六道闸

任何选题进入选题池前，必须**逐道通过**，任何一道不过就丢弃：

1. **跟这个 IP 的定位相关吗？**（**第一道，也是最容易被忽略的**）不相关直接丢弃，**不要凑数**。
2. **有保险思维内核吗？** 没有就只是蹭热点，删掉。
3. **前 8 秒能站住吗？** 有没有冲突、悬念、反差或利益关联。
4. **跟观众的钱/工作/家庭/身份/选择有关吗？** 无关则无人转发。
5. **有品味吗？** 见下方红线。
6. **能展开成一段 ≤700 字的口播吗？** 只有一句话的感想不成片。**全包统一 ≤700 字（硬上限），任何 IP 没有例外**；撑不满就说明题太薄，直接丢弃，不要靠注水凑字数。

> **宁可只交 7 个扎实的选题，也不要凑满 10 个水的。** 用户要的是能拍的题，不是填满的表格。

## 四、品味红线（不可触碰）

- ❌ 低俗、擦边、恶搞、猎奇到失格
- ❌ 贩卖焦虑并止于焦虑（必须给出认知升级或行动出口）
- ❌ 攻击特定群体、地域、性别对立、引战
- ❌ 蹭灾难、事故、死亡事件做流量
- ❌ 编造故事、编造数据、编造身份经历
- ❌ 承诺收益、制造恐慌、暗示「买了就解决」
- ❌ 直接讲产品名、公司名、条款、收益率

**判断标准**：这条内容发出来，一个高净值客户看到会觉得「这个人值得信任」还是「这个人掉价」？后者一律不做。

| 避免 | 替换为 |

| 理财、投资、暴富 | 选择权、现金流、抗风险能力 |
| 保诚、具体产品名 | 完全不提 |

## 七、选题池输出格式（10 个选题）

一次出 **10 个选题**（编号 T1–T10），每条包含：

| 字段 | 说明 |
|---|---|
| 编号 | T1–T10 |
| 大兴趣点 | 归类（可用自行归纳的新类别） |
| 热点来源 | 具体事件 / 话题 + 来源，必须真实可核 |
| **保险理念结合点** | 接的是哪个保险知识点或理念，说明机制（不能只写「保险很重要」） |
| **击中哪个痛点** | 该 IP 客群的哪个具体痛点 / 买点 |
| 选题标题 | 一句能抓住人的话，20 字内 |
| 事实支撑 | 1–2 个可核实的数据/案例/来源 |
| 传播指数 | 1–5 星 + 一句话理由 |
| 合规预判 | 绿 / 黄（需弱化） / 红（不做） |

**「保险理念结合点」和「击中哪个痛点」写不出来的选题，直接删掉，不要硬写。**

### 交付页（HTML）—— 强制按模板出，格式固定

选题池**必须以可勾选网页交付**，不允许只发一张表格。基准文件：`assets/选题池模板.html`。

铁律：

- **CSS 与 JS 一律照抄模板，不得改写、不得换配色、不得改布局**——这套展示形式用户已确认固化。
- `article.topic` 复制 10 份（T1–T10）逐张替换；每张卡**四处 `data-topic` 必须与卡号一致**：
  `article` / `input.drop` / `textarea` / `input.customflag`。
- 生成后**不得残留 `{{ }}` 占位符**；页头统计（选题数／合规色数／字数口径）按本批真实情况填。
- 若有选题被相关性闸门丢掉，就照实少给（如 8 个），页头写真实数。

模板已内置两处交互，**必须保留**：

| 能力 | 位置 | 用户怎么用 | 主理人怎么接 |
|---|---|---|---|
| **本轮不做** | 每张卡右上角 `.dropbox` | 勾选 → 整卡置灰划线，该题下立意自动取消勾选 | 复制结果里单列【本轮不做】；**这些题本轮不写稿、不进 Notion**，也不必追问原因 |
| **我自己有想法 / 想补充** | 每张卡立意区最后一条 `.angle.custom` | 文本框里写内容即自动选中 | 复制结果里以「└ 我的想法：…」附在该题之后；**写稿必须照此调整立意**，不得忽略、不得自行改写用户原意 |

复制出的文本形如：

```
香港胡子哥 · 选题勾选（2026-09-22）

【本轮不做】T3、T7
【保留】T1、T2、T4、T5、T6、T8、T9、T10

T1-d
T5-c
   └ 我的想法：结尾想落到「先算每月能流出多少」，别提具体产品
```

主理人收到后，**逐条按【保留】+ 所选立意 + 我的想法**进 W2，**不要自行把被剔除的题捡回来**。

## 八、立意点输出格式（每个选题 5 个）

选题池交付后，**每个选题再拆 5 个立意点**（编号如 T3-a ~ T3-e）：

| 字段 | 说明 |
|---|---|
| 编号 | 所属选题号 + 序号 |
| 立意点标题 | 一句话，20 字内，体现立场 |
| 核心主张 | 2–3 句说清主张什么 |
| 切入角度 | 反常识 / 拆解规则 / 对比 / 追问动机 / 拉回个人选择 |
| 支撑 | 事实、数据或案例（查不到标【待核实】） |
| 观众落点 | 看完在什么选择上被打动 |
| 意外感 | 反差 / 悬念 / 反常识在哪 |

**五条立意点必须有辨识度。** 用户一眼看过去觉得「这五条差不多」，就是失职。
**严禁泛泛播报新闻**——只把新闻复述一遍的立意点，没有立意，重写。

## 九、相关性闸门（第一道闸展开）

抓到热点后，先问三个问题，**三个都过**才保留：

1. **这个大兴趣点跟该 IP 的内容定位相关吗？** 不相关 → 丢弃
2. **它能接上 ima 里查到的保险理念吗？** 接不上 → 丢弃
3. **它能击中该 IP 客群的具体痛点吗？** 击不中 → 丢弃

检索 ima 时**按用途分库查**（产品 / 行政 / 核保 / 理财 / 竞品），不要全库搜索，结果会发散。
用该 IP **客群的关键词**去查（客群是港漂就查港漂关心的医疗、续签、资产规划），
不是拿热点去硬套保险。

### 从对标库捞来的题：再加两道闸（2026-09-23）

4. **IP 匹配闸** —— 该题的 `内容领域` / `目标受众` 与这个 IP 对得上吗？对不上 → 丢弃
5. **素材缺口闸** —— 选题实验库有「需要的真实素材」字段，**IP 拿得出来吗**？
   拿不出 → 标【需 IP 提供素材：XXX】交给用户，或丢弃。**不许替 IP 编经历。**

**接保险的尺度（用户拍板，必须标在选题卡上）**：

| 类型 | 要不要接保险 |
|---|---|
| 保险专业向 | **必须接** —— 落不到保险知识点或理念就丢弃 |
| 中年转型 / 职业类 | **可挂招募向** —— 接「转行做港险」的招募线索 |
| 流量向 / 人设向 | **不必接** —— 但必须标明「本条不带保险落点」 |

> 库里标注「待验证」的选题不算已验证；点赞高只是**一次表现**，不能写成「这套跑通了」。
