## 这是什么

一支「虚拟内容团队」。你把需求丢给它，它按固定工作流派活给 5 个不同角色，最后交给你可直接拍摄的口播逐字稿与发布文案。

旗下所有 IP 做的都是**香港保险自媒体**，但客群各异、保险击中买点的方式也不同 —— 所以它不只产文案，还会**先确认这条是给哪个 IP 写的**，再按那个人设卡的语气、规格来写。

```
定 IP → 学 ima 保险知识 → 抓热点 + 捞对标库 → 过三道闸 → 出 10 选题 × 5 立意（可勾选网页）
      → 用户勾选 → 写 ≤700 字口播稿 → 合规终审 → 出标题/简介/标签 → 写入 Notion
```

## 快速开始

### 方式 A · 从 Release 下载（推荐给只用不改的人）

1. 到 [Releases](https://github.com/tychowu/yzzx-content-studio/releases) 下载最新版 `yzzx-content-studio-vX.Y.Z.zip`
2. WorkBuddy → **专家中心 → 导入专家** → 选这个 zip
3. ima / Notion 的授权步骤见下方「外部依赖」一节（首次使用需管理员先把你加进对应共享库）

### 方式 B · 克隆仓库（推荐给要改的人）

```bash
git clone https://github.com/tychowu/yzzx-content-studio.git
bash yzzx-content-studio/sync.sh      # 安装 / 更新到最新版，并自动重新注册
```

`sync.sh` 的三种模式：

| 命令 | 作用 |
|---|---|
| `bash sync.sh` | 安全更新：本地有未提交改动就停下，**绝不覆盖你** |
| `bash sync.sh --check` | 只看本地 / 远程版本差多少，什么都不改 |
| `bash sync.sh --reset` | 丢弃本地改动，硬对齐远程（**危险**） |

### 装好之后

第一次对话它就会做两件自检：**① 连接器**（ima / Notion 是否已授权）、**② 版本**（本机是否落后于仓库，落后就自动更新）。
然后直接说人话，例如：

- 「给香港胡子哥出 10 个选题，每个 5 个立意点」
- 「我有条素材（附链接），帮我出选题和立意」
- 「这个立意确认了，写 ≤700 字口播稿，合规后出标题和标签」

## 工作流

| Workflow | 什么时候用 | 做什么 |
|---|---|---|
| **W0 前置自检** | *每次调用自动触发* | 确认 ima + Notion 已授权；顺带核对本机版本是否最新（落后则自动更新）；报出版本号 |
| **W1 选题池** | 说「出选题」「这周拍什么」+ 指定 IP | 学 ima 保险知识 → 抓热点（含「香港故事」常设主线）→ 捞对标博主蒸馏库 → **相关性闸门 + IP 匹配闸 + 素材缺口闸** → 出 10 选题，每个拆 5 个立意 → 出**可勾选选题池网页** |
| **W2 口播成稿** | *勾选完立意后自动进入* | 按该 IP 定位写 **≤700 字**口播稿，五层结构 + 情绪波浪 + 信息钩子链 + **去 AI 味写作法（硬门槛）** |
| **W3 合规终审** | *成稿后自动进入* | 三查：事实核查 / 三平台敏感词与**引流词** / 香港保险内地宣传合规 |
| **W4 发布包** | *终审通过后自动进入* | 标题 10 个（≤10 字）+ 简介 5 个（20–30 字）+ 三平台标签 → 写入 Notion（正文固定五个可折叠 H4 板块） |
| **W5 素材速写** | 你手上有现成素材并说「就拍这个」 | **先问清「这条给哪位 IP 写」**（素材形式不限）→ 跳过抓热点，直接用你的素材接保险理念 |
| **W6 复盘迭代** | 说「复盘」「这批数据怎么样」 | 分析哪类选题跑得好、下期建议；多 IP 时按 IP 分开看 |

> **W1 的「选选题 + 选立意」是不可跳过的用户决策点** —— 没选就不进写稿。
> **宁可只给 7 个扎实的选题，也不凑满 10 个水的。**

## 成稿规格

| 规格 | 字数 |
|---|---|
| **默认（全包统一，8 个 IP 无例外）** | **≤700 字（硬上限）**，建议 620–700 |
| 90 秒 | 540–660 字 |
| 60 秒 | 360–440 字 |
| 30 秒 | 180–220 字 |

语速口径 **约 360–440 字/分钟（快节奏口播）**，700 字 ≈ 1 分 40 秒。

五层结构：**钩子 0–8s（45–55 字）/ 铺垫 8–30s（120–145 字）/ 主体 30–86s（325–375 字）/ 升华 86–96s（58–68 字）/ 引导 96–105s（45–55 字）**，合计 593–698 字，天然卡在 700 内。

> ⚠️ **字数上限是硬的，没有例外。** 曾经出现的 `720–880` / `650–850` / 上限 `1100` 等写法**全部取消**；卡上若还写着旧规格，一律按 ≤700 执行。

## CTA 三词禁令（2.9.0 新增，重要）

**「微信」「私信」「评论区」这三个词，成稿里一个字都不许出现** —— 包括结尾的行动呼吁、正文、标题、简介、标签。

平台会把它们自动识别成**引流**，判定后**直接压推荐流量**，内容再好也推不动。同禁组合变体（加微信 / 私信我 / 评论区留言 / 扣在评论区…）。

| 想要的效果 | ❌ 不能写 | ✅ 改成 |
|---|---|---|
| 引导讨论 | 去评论区说说你的看法 | 「你怎么看？」「你身边有没有这种情况？」 |
| 想要对话 | 私信我，我们细聊 | 「关注我，下条我把这块讲透」 |
| 留资料 / 联系方式 | 资料在主页，加微信领 | 不给联系方式，改成价值承诺（「下条讲 XXX」） |

规则详情见 `skills/ip-voice-playbook/SKILL.md` §6.9。

## 文风硬规范：去 AI 味

文字要像人说的话。稿子一旦工整、抽象、四平八稳、每句都对，就会被划走。

| 维度 | 硬要求 |
|---|---|
| **句子** | 长句拆短、长短交错；**不要一句一段**，也不要通篇对仗 |
| **语态** | 少用被动；不背套话连接词（首先 / 其次 / 综上所述 / 不难发现） |
| **用词** | 空泛抽象词换成能看见的东西 |
| **视角** | 把「我」从主角位撤下来（只留钩子设问与结尾 CTA）；禁「我觉得 / 我认为」 |
| **开头** | **必须是爆款开头**：第一句就有冲突或反差，不含「我」，钩子层 ≤35 字 |
| **结尾** | 先收（金句能单独截图）→ 再升华 → 最后递一个当天能做的动作；必须有一句互动或 CTA |

## 版本与发布

版本号规则 `x.y.z`（完整判据见 [`RELEASE.md`](RELEASE.md)）：

| 变化 | 升位 |
|---|---|
| 角色 / 工作流结构变了，老提法拿不到对的结果 | **x**.0.0 |
| 多了新能力 / 新必经步骤，或口径变了 | 0.**y**.0 |
| 只是改字、改数字、换图 | 0.0.**z** |

**每次发版都会**：更新 `plugin.json` 版本号与卡片描述 → 写进 `CHANGELOG.md` → git commit + tag → 在 [Releases](https://github.com/tychowu/yzzx-content-studio/releases) 建一条带说明的 release（附对应 zip）。

装的是哪一版？看 WorkBuddy 专家卡片底部的 `vX.Y.Z`。

### 发布节奏（维护者必读）

**改动是改动，发布是发布，两件事分开做。**

| 阶段 | 做什么 | 什么时候 |
|---|---|---|
| **① 改** | 只改源目录里的文件，**不动版本号、不打包、不推送** | 随时，改完攒着 |
| **② 发布** | 升版本号 → 校验 → 打包 → commit + tag → 推送 → 建 Release（附 zip） | 只在仓库主人明确说「发布 / 发版 / 更新一版 / 推一下」时 |

- **别改一处发一版** —— 一天改五处攒着发一次，版本号才不会虚涨。
- **发布后不单独传包**：zip 只在 GitHub [Releases](https://github.com/tychowu/yzzx-content-studio/releases) 页，同事自己去下最新版。
- 同事本机不用手动折腾：`bash sync.sh`，或下一次对话时 **W0 版本自检**会自动把它拉上去。

## 贡献

改法见 [`CONTRIBUTING.md`](CONTRIBUTING.md)，一句话版：

```bash
git pull                      # 先拉别人的改动，别闷头覆盖
# …改文件…
git add -A && git commit -m "改了什么：例如 收紧 CTA 禁词"
git push
```

- 小改动（文案润色、补 IP 卡）直接 push `main`
- 大改动（成员结构、技能重构、版本升级）开 **Pull Request**
- `avatars/*.png` 等二进制**只在 `main` 由仓库主人改**
- **绝不提交密钥 / token / 个人敏感信息**
- 改完记得 `bash sync.sh` 重新注册，本机才生效
